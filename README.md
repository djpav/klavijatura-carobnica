# 🎹 Klaviatura Čarobnica

Interaktivna igra za decu - pritisni bilo koji taster na tastaturi ili klikni mišem i gledaj šta se desi!

## [▶ Play Now!](https://djpav.github.io/kavijatura-carobnica/)

### Kako se igra

- Pritisni bilo koji taster na tastaturi - pojavljuju se emoji balončići sa zvukom!
- Klikni ili tapni bilo gde na ekranu
- Brzo pritiskanje tastera gradi **combo** za veće efekte
- Swajpuj levo/desno (mobilni) ili klikni temu dole za promenu emoji kategorije

### Teme

- 🌈 **Sve** - mix svih emojija
- 🐾 **Životinje** - životinje i bube
- 🍕 **Hrana** - hrana i piće
- 🚀 **Svemir** - svemirski objekti i efekti
- 😀 **Smajliji** - lica i izrazi
